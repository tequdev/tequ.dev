# tequ.dev

tequ's personal page. A single-page Astro static site.

## Commands

```bash
pnpm dev
pnpm build
pnpm preview
```

## Well-known files

`public/.well-known/xrp-ledger.toml` and `public/.well-known/xahau.toml` must not be edited.

## Deploy

Vercel **Astro** preset, output `dist/`. Not Next.js, not Other/static.

Set the Vercel project Node version to **22.x** (Astro 7).
